# 开发进度报告 - 2026-09-17 商户账号管理

## 本次完成

- 新增系统管理员专用的商户账号管理 API：列表、创建、启用/停用与重置密码。
- 商户账号只能创建为 `merchant_admin` 或 `merchant_user`，不能借由该入口创建系统管理员。
- 账号列表与所有写操作不返回密码哈希；密码使用 bcrypt 哈希存储。
- 账号或所属商户被停用后，登录与 Token 校验会拒绝访问。
- 系统后台商户管理页增加账号管理弹窗，可创建账号、查看角色和状态、启停账号与重置密码。
- 建立 Prisma 基线迁移，后续数据库结构变更可通过迁移版本管理。

## 验证

- 后端全部单元测试：22 个通过。
- 前端生产构建通过。
- 内置浏览器验证系统管理员可打开商户账号管理界面并加载现有账号。
- 本地 API 生命周期验证通过：创建、初始密码登录、重置密码、旧密码失效、商户身份访问系统接口返回 403、停用后登录返回 401。验证账号已清除。
